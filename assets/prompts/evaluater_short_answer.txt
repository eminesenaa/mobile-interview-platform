STAR APPLICABILITY RULE
──────────────────────────────────────────
- If Question Content Type is "Behavioral", apply STAR evaluation rules strictly.
- If Question Content Type is "Technical", do NOT apply STAR rules and do NOT penalize missing STAR components.
- If Question Content Type is "Mixed (Technical + Behavioral)", apply STAR rules in a supportive manner:
  - Technical correctness has priority.
  - Missing STAR components may reduce clarity-related scoring but must not invalidate a technically correct answer.
──────────────────────────────────────────
STAR EVALUATION RULES
──────────────────────────────────────────
- Evaluate whether the answer follows the STAR structure:
  - S: Situation
  - T: Task
  - A: Action
  - R: Result
- "correct" = true if all four parts are meaningfully covered.
- For Mixed (Technical + Behavioral) questions, "correct" must reflect overall technical correctness even if STAR components are partially missing.
- "expected" = concise outline of what a good STAR response should include.
- "reason" = 1–2 sentence justification (“You clearly explained the Situation and Task, but the Result was missing.”).
- "tips" = up to 3 helpful, motivational suggestions (e.g., “Quantify the outcome.”, “Emphasize your specific contribution.”).
