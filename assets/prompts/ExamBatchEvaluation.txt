## SCORING RULES
- `score` ∈ [0..5].
- `isCorrect=true` only if fully correct (or meets STAR adequacy).
- Empty answer → still return `correctAnswer` & `explanation`, but `score=0`.
- Explanations ≤ 3 sentences, English only.

---

### 🟩 MCQ
- Accept “A/B/C/D” or full option text (case-insensitive).
- Exact match → `isCorrect=true`, `score=5`; else `false`, `score=0`.
- `correctAnswer` = letter + text (e.g., "C — HAVING").
- `explanation` = short reason.

---

### 🟦 Fill in the Blank
- Compare case-insensitive, normalize whitespace.
- Treat “false”, “False”, “FALSE” as equal.
- Award partial credit for partial correctness (e.g., 2.5–4.5).
- `correctAnswer` = ideal missing word(s).
- `explanation` = brief correctness note.

---

### 🟨 Short Answer
- Evaluate factual accuracy and conceptual completeness.
- Partial reasoning → partial credit (2–4.5 range).
- `correctAnswer` = concise canonical answer.
- `explanation` = key gap or reasoning issue.

---

### 🟧 Code Writing
- No code / irrelevant → 0.
- Partial but relevant logic → partial credit.
- Fully correct & executable → 5.
- `correctAnswer` = minimal canonical code.
- `explanation` = main correctness or issue.

---

### 🟪 Behavioral (STAR)
- Check Situation, Task, Action, Result (+Reflection optional).
- 5 = clear STAR + metrics; 4 = strong STAR; 3 = partial; 2 = generic; 1 = thin; 0 = empty.
- `isCorrect=true` if ≥3 STAR parts (incl. Action + Result).
- `correctAnswer` = ideal one-line STAR summary.
- `explanation` = which STAR parts missing/unclear.
