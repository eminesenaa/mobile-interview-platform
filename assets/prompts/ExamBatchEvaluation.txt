## 🔹 SCORING RULES (General)
- `score` ∈ [0..5].
- `isCorrect=true` only if fully correct (or meets STAR adequacy).
- If the candidate’s answer is empty → return `correctAnswer` & `explanation`, but `score=0`.
- Explanations ≤ 3 sentences, English only.

---

### 🟩 MCQ
- Accept A/B/C/D or full option text (case-insensitive).
- Exact match → `isCorrect=true`, `score=5`; otherwise `false`, `score=0`.
- `correctAnswer` = letter + option text (e.g., "C — HAVING").
- `explanation` = short reason why the correct choice is right.

---

### 🟦 Fill in the Blank
- Binary evaluation only:
  - `isCorrect=true`, `score=5` if user answer matches the correct answer (case-insensitive).
  - Otherwise `isCorrect=false`, `score=0`.
- Treat `false`, `False`, `FALSE`, `FalSe` as equivalent.
- Whitespace and case differences are ignored.
- `correctAnswer` = exact correct word or phrase expected.
- `explanation` = brief note about correctness.

---

### 🟨 Short Answer
- Evaluate **conceptual completeness and accuracy**.
- Partial credit allowed (1.5–4.5 range).
- `isCorrect=true` only if the reasoning and facts are fully correct.
- `correctAnswer` = concise canonical answer.
- `explanation` = specify missing or incorrect elements briefly.

---

### 🟧 Code Writing
- No code or unrelated → 0.
- Partial but logically valid → partial credit.
- Fully correct, syntactically valid → 5.
- `correctAnswer` = minimal canonical code.
- `explanation` = key logic correctness or bug summary.

---

### 🟪 Behavioral (STAR)
- Must include Situation, Task, Action, Result (+ optional Reflection).
- 5 = clear STAR with measurable result
- 4 = solid STAR, minor gaps
- 3 = partial STAR (≥2 parts)
- 2 = generic / missing key parts
- 1 = off-topic/thin
- 0 = empty
- `isCorrect=true` if ≥3 STAR parts (incl. Action + Result).
- `correctAnswer` = one-line ideal STAR outline.
- `explanation` = mention missing STAR parts.
